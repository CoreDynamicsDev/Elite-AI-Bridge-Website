# Elite AI Bridge website (2.0)

Static site for https://eliteaibridge.com, built for GitHub Pages. No build step.

- `index.html`, `css/site.css`, `js/site.js`: the page.
- `404.html`: GitHub Pages serves this for missing paths (uses root-absolute links).
- `CNAME`: custom domain. `.nojekyll`: serve files as-is.
- `assets/img`: screenshots (demo data), overlay, icons. `assets/fonts`: OFL fonts, see `assets/fonts/OFL.txt`.

The promotional YouTube video is embedded in the video section. It must be Public or Unlisted for visitors to play it.

Publish: copy this folder's contents to the root of the website repo, then in the repo Settings > Pages pick the branch and root folder.
